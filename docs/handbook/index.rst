Handbook
========

Handbook, architecture and concept notes and decision logs from the project's Obsidian vault
(``knowledge/`` in the repository). The vault is the single source: these pages are
regenerated by ``scripts/export_knowledge.py`` on every documentation build. Open the
repository as an Obsidian vault for the live dashboard, the Code Graph view and the
issue notes and the papers list.
