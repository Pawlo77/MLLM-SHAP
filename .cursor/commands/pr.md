# PR

Skill `ship` opens and drives the pull request; use it. The body template below is what `pr-writer` fills.

1. The exit criteria in `AGENTS.md` are green.
2. Run the `pr-writer` agent for the title (commit style) and the body, which follows `.github/pull_request_template.md` (the label carries the type of change; commands run and their results under "Notes for reviewers").
