# SGPA

SGPA (Spectrogram-Guided Phonetic Alignment) aligns an audio signal to phonetic units so that audio segments, rather than individual frames, become players; it makes Shapley explanations of speech input feasible. It is planned for the audio track and has no code in nlp-shap yet.

Source: arXiv [2603.02250](https://arxiv.org/abs/2603.02250) (listed in the legacy MLLM-Shap README). Roadmap: [[Roadmap]]; deferred work: [[D02 - Audio backend]].
