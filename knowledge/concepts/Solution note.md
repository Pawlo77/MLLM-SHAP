# Solution note

A solution note records how one solved problem was solved: the problem, what was tried and why it failed, what worked, and one reusable rule (`type: solution`, under `knowledge/handbook/Solutions/`). Skill `vibe` writes it after a pull request (PR) merges, and review and brainstorming read the folder first so a solved problem is not solved twice; a design choice still gets a decision section and a bug an issue note.
